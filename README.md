# FSFP: Free Software for People

**نرم‌افزار آزاد برای مردم**

شعار: **نرم‌افزار آزاد، جامعه آزاد**

جملهٔ راهنما: نرم‌افزار آزاد دربارهٔ آزادی است، نه قیمت. به آزادی بیان فکر کنید، نه به آبجو رایگان.

سایت هوگوی FSFP به فارسی. محتوا از پروژهٔ «جنبش نرم‌افزار آزاد» آمده و با هویت **Free Software for People** جلو می‌رود.

| | |
| --- | --- |

| English | Free Software for People |

| Site | https://fsfp.ir |

## اجرا

```bash
hugo server
```

سایت روی `http://localhost:1313` بالا می‌آید.
